## ④ 四大赛道：机器人只是其中一个

他点名的四个方向里，真正意义上的「机器人」只有一个，但另外三个都建立在同一套底层能力上。

| 赛道 | 他的说法 | 核心逻辑 |
| ---- | -------- | -------- |
| ① 具身智能（人形机器人） | 物理 AI 的「身体」；2026 年是爆发第一年；整机行业会大量洗牌，真正的机会在上游零部件 | **卖铲子**——不管哪家整机厂赢，零件供应商都能赚 |
| ② 无人机 | AI 在真实世界里第一个跑通商业闭环的形态。战场无人机在替代坦克，农田和物流在省人工，军用和商用两个市场同时变大 | 不需要走路，飞起来比双足行走简单；天然适合 AI 做的自主导航和群体协同 |
| ③ 空间计算 | 被大多数人误读成 VR。他的看法是：这是让 AI 理解真实世界里「东西在哪、离多远」的关键 | 机器人、无人机、自动驾驶共同的前提——都需要空间智能 |
| ④ 太空探索 | 他个人最看好的终极方向，也是唯一一个他「肉身去过」的。2025 年 8 月坐蓝色起源飞过卡门线 | 为以后两件事做准备：太空资产确权、跨星球支付 |

### 这四个赛道其实是同一件事

::: tip 物理 AI 全图景
把四件事拼起来看，就是他自己讲的「物理 AI 全图景」：**机器人负责干活，无人机负责先落地，空间计算提供感知基础，太空是终极延伸。** 它们共享同一套底层能力——让 AI 从「理解文字」过渡到「理解世界本身」。
:::

### 一个值得注意的内部排序

他虽然把人形机器人放在第一位讲，但他自己的分析里其实承认无人机走得更前面：他说「人形机器人还在量产爬坡，无人机已经先一步走到商业落地」。

也就是说：

- 论「**已经赚到钱的确定性**」，他的排序是 **无人机 > 人形机器人**；
- 论「**未来的想象空间**」，他把**人形机器人**放在前面。

这两句话要分开读。

## ⑤ 怎么投：不押整机，押零部件

这是他机器人观点里最「可操作」的一部分，也是唯一能拿去检验的。

### 机器人这条线：身体和大脑分开押

| 押「身体」→ 特斯拉 | 押「大脑」→ 英伟达 |
| ------------------ | ------------------ |
| 理由是它的产线动作最实：2026 年初停产 Model S 和 Model X，把弗里蒙特工厂改造成 Optimus 产线，目标年产百万台，量产单价约 2 万—2.5 万美元。现有版本已在工厂做零件搬运分拣。 | 理由是它谁都绕不开：Jetson Thor 把服务器级推理塞进机器人本体，Isaac GR00T 几乎成了行业通用底座。 |

::: tip 这两笔背后的逻辑是同一句话
「Optimus 能不能如期兑现是马斯克的问题，不是英伟达的问题；赛道只要跑通，过路费就会照收。」
:::

### 通用投资原则：三条

| 原则 | 内容 |
| ---- | ---- |
| 原则一 | **两端布局，不押单一公司。** 以机器人赛道为例，同时布局硬件零部件与 AI 算力芯片，分散个股暴雷风险 |
| 原则二 | **坚守上游，坚决不追整机整车。** 整机竞争极度激烈，上游核心元器件是全产业链共同受益的环节 |
| 原则三 | **买「确定的方向」，不买「确定的公司」**——整个方向涨的时候，不管哪一家跑出来他都能赚到 |

### 他点名过的具体环节

执行器、减速器、伺服电机/无框力矩电机、稀土磁材（钕铁硼）、传感器、3D 视觉传感器、激光雷达。

共同点是：这些都不是只存在于电脑里的东西，而是**机器本身**，或者机器要用到的零件和信息通道。

::: warning 方法论本身要留一个问号
「卖铲子」逻辑成立的前提是这个赛道真的会大规模起量。如果人形机器人的量产进度持续低于预期，那么零部件供应商同样会面临产能过剩。

**它分散的是「个股风险」，不是「赛道风险」。** 这一点他的公开表述里没有展开。
:::
