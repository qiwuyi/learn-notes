# 小米建议与时间线

## ⑧ 对小米、雷军的建议

这是他机器人观点里最「出圈」的一段，因为它针对的是一家具体公司。

::: tip 原话
「雷军应该卷机器人，别卷汽车了。」

——2026 年 9 月被重新翻出传播的一段**旧视频**
:::

### 他讲的完整逻辑

- **对造车的判断**：小米进汽车制造业有些后知后觉。雷军早期投资策略与腾讯相似，后来因为汽车估值过高才决定亲自下场。小米汽车配置不错，但 21 万元左右的定价对目标群体而言太贵了。
- **对机器人的判断**：更看好小米在机器人领域的潜力。「小米的机器人加大模型组合，潜能远超其汽车业务。」
- **给出的理由**：从造车转向机器人，不仅能「把那些初创公司卷哭了」，还可能更快迎来如 ChatGPT 般的「wow 时刻」。
- **给的切入路径**：优先利用小米在生活家电领域的优势，「先把炒菜机器人、生活家电全给卷完」。

::: warning 背景要一起看
他本人曾在社交媒体高调展示小米机器狗，重金押注小米生态产品，也说过自己家里几乎全部换成米家产品、连炒菜机器人都安排上。**所以这不完全是一个中立第三方的产业判断，里面同时有他自己持仓立场的成分。**

另外要注意：这段视频是**旧视频被重新翻出传播，不是新发言**。传播时点（2026 年 9 月）恰好是全球物理 AI 概念最热的时候。
:::

## ⑨ 机器人相关时间线（2024—2026）

把散落的动作按时间排开，能看到一条清晰的铺垫路径：**先有「机器人开不了银行账户」，后来才有「物理 AI 是主线」。**

| 时间 | 事件 |
| ---- | ---- |
| 2024-05-06 | 发帖说自己在给一只机器狗写程序，并提了一个问题：AI 加上这套链，能不能做成安全的交易。（这是一个问题，不是产品发布） |
| 2024-10-19 | 改写机器人三定律为「AI 迷因币伦理三定律」。 |
| 2024-11-21 | 「机器人开不了银行账户」那段对谈。他说 AI 程序要收钱应该用链上地址。（自动字幕，大意） |
| 2025-01-04 / 01-06 | 「All in AI」；三天后的中文长帖：走向智能体主导的时代，AI 将在资源分配、金融决策上发挥重要作用。 |
| 2025-08-03 | 乘蓝色起源「新谢泼德号」完成亚轨道飞行，为太空资产确权和跨星球支付做铺垫。 |
| 2026-02 | 香港会议：连电影里的机器人要付钱也得用区块链。 |
| 2026-03-23 | 波场 DAO 新闻稿：AI 基金从 1 亿扩大到 10 亿美元，重点投智能体经济的基础设施。（仍未公布被投公司） |
| 2026-05-14 / 05-16 | **关键节点。** 他在视频和社交平台同步发声：划出四大科技主赛道，「虚拟 AI 红利彻底结束，未来 3–10 年唯一主线是物理 AI」；并定下「不追整机、投上游零部件」的投资方法论。（注：此为该事件的媒体报道时点，原帖未逐字核对） |
| 2026-07 | 东京 WebX 大会：AI 智能体需要可验证的数字身份、独立资金管理、开放支付通道三样东西。 |
| 2026-09-04 | 「建议雷军别卷造车去卷机器人」的旧视频被重新翻出，引发讨论。 |
| 2026-10-11 | 再放判断：2026 是「下一个十年的分水岭」；对话式 AI 红利已啃完，物理 AI 才是下一个爆发点。 |

::: tip 时间线上最重要的一条观察
机器人这条线**不是 2026 年才出现的**。它从 2024 年 5 月的「给机器狗写程序」就开始铺垫，2024 年 11 月的「机器人开不了银行账户」是第一次完整表述——比 2026 年那一波**早了整整一年多**。

而这条线从第一天起就服务于同一个目的：**证明 AI 需要一个链上账户。**
:::
