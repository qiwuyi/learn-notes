# 孙哥对机器人的观点 · 深度解读与联网调研汇总

从「屏幕里的 AI 已经到顶」到「物理 AI 是未来十年唯一主线」——把孙宇晨散落在社交平台、大会演讲、投资动作和产品发布里的机器人判断，拼成一条完整的逻辑链，并逐条核对证据强度。

- **整理时间**：2026-10-12
- **性质**：公开信息的通俗整理与第三方视角分析，只供了解使用，**不构成任何投资建议**

## 一句话看懂：他的机器人观点是什么

如果只看一句话，那就是：**AI 的价值正在从「处理信息」转向「操作物理世界」，而机器人是这件事最主要的载体。**

::: tip 核心判断
「大众化的虚拟 AI 红利已经彻底结束，未来三年核心机会只有物理 AI。」

——2026 年 5 月，他在微博、雪球、波场官网同步发声；同期把波场 DAO 的 AI 基金从 1 亿美元扩到 10 亿美元，方向从虚拟 AI 转向物理 AI。
:::

围绕这一句，他的机器人观点可以拆成五层。这五层从「世界会变成什么样」一路收到「我现在买了什么」，层层往下：

| 层 | 标题 | 内容 |
| - | ---- | ---- |
| 第一层 | 判断 | 屏幕里的 AI（聊天、写文案、生成图片）只在处理信息，碰不到真实世界，所以作用有天花板。机器人、无人机、自动驾驶这类「能看见、能走、能动手」的 AI，面对的是真实的生产和运输，空间大得多。 |
| 第二层 | 时机 | 他把 2026 年定为物理 AI 爆发的第一年，并说机器人「快到 wow 时刻了」。理由是过去做不出来是因为「大脑」不行，而现在 VLA 模型让机器人从「照代码做」变成「看着眼前做」。 |
| 第三层 | 怎么投 | 不押整机厂商，押上游核心零部件——电机、减速器、传感器、稀土磁材。理由是「整机行业未来两年会大量洗牌，但不管谁跑出来，都得买零件」。 |
| 第四层 | 怎么用 | 机器人要真正进入经济活动，必须能自己付钱。而银行不给机器人开户，所以机器人只能用区块链地址做身份和账户。 |
| 第五层 | 谁受益 | 这条链的最后一环，落在他自己的产品上：B.AI、Bank of AI——给 AI 智能体和机器人提供身份、账户和支付通道。 |

::: warning 关键提醒
这五层里，只有第一、二层是「产业判断」（可以拿去检验），第四、五层是「生意论证」（要知道他为什么这么说）。第三层是投资方法，介于两者之间。
:::

::: tip 一句话总结
他对机器人的观点，本质上是「资本周期判断」，而不是「工程技术判断」。他谈的是「钱会往哪流、什么时候流」，而不是「机器人怎么做出来」。他自己也说过：大概率不会下场造机器人。
:::

## 读之前：三种证据强度，先分清楚

同一个意思，由不同的人留下，分量完全不同。这是他这份材料里最重要的一个方法，也是所有二手转述最容易出错的地方。

| 证据类型 | 判定标准 | 在机器人话题上的例子 |
| -------- | -------- | -------------------- |
| 本人原话 | 原帖现在还能打开，或用引号写出的原话 | 2024-10-19 改写阿西莫夫三定律的帖；2025-01-04「All in AI」；2026-02-21 机器人付钱那条帖 |
| 公司新闻稿 | 波场 DAO / HTX / 他办公室写好发给媒体刊登。说明「公司希望大家知道」，不等于已经做成 | 2026-03-23 AI 基金从 1 亿扩到 10 亿美元；波场 DAO「欢迎」B.AI 上线 |
| 记者/字幕转述 | 记者用自己话重说、英文现场翻译、自动生成字幕。只能说明「当时大概在谈这个」 | 2024-11-21 对谈的自动字幕；2026-04-21 香港圆桌的英文整理稿 |

### 四个最容易搞混的地方

1. 被他 @ 到的人，不等于答应了；
2. 转发别人的帖，不等于他自己做的产品；
3. 一场活动他是赞助商，和他自己发布产品是两件事；
4. 公司把两件事写在同一篇稿子里，不等于这两件事有关系。

### 还有一条：分清「说过」和「做到」

宣布要做 → 已经做出来 → 已经卖出钱，是三件不同的事。在机器人这条线上，他大量用的是「将会」「即将」「快到了」，这些都要当**未来时**读。
