# ③ 核心命题：为什么是机器人，而不是别的

他的推理只有四步，但每一步都指向同一个结论。

## 第一步：先把 AI 分成两类

他把 AI 划成两条线：

- **屏幕里的 AI（虚拟 AI / 感知·生成·对话）**：你打字问它，它给你文字或图片。它能处理信息，但碰不到真实世界里的东西。
- **物理 AI（具身智能）**：把 AI 接到真实世界的机器上——机器人、无人机、自动驾驶的车。这些机器有传感器（能感光、测距、测压力），有马达（能动手）。所以这种 AI 能看见、能走、能拿东西。

::: info 术语说明
「物理 AI」和「具身智能」说的是同一类东西，只是说法不同。行业内英伟达的黄仁勋从 2024 年起就在推「Physical AI」这个说法。
:::

## 第二步：说屏幕里那条线「到顶了」，给三个理由

| 理由 | 他的说法 | 站不站得住 |
| ---- | -------- | ---------- |
| 大模型进步变慢 | GPT-4 之后新版本提升越来越小，各家产品差别越来越小，普通用户感觉不出区别 | **有争议**——行业内确实在讨论，但说法不统一 |
| 赚钱难 | 生成图片很厉害，但用户愿意为它花多少钱？收入涨得快、利润很薄，愿意付钱的人有上限 | **部分成立**——是行业普遍讨论的问题 |
| 只解决「信息问题」，不解决「生产问题」 | 它能帮你写一封更好的邮件，但这封邮件不能帮你把一箱货搬走 | **较硬**——这条区分很难被反驳 |

::: tip 他自己的原话（转述）
「原来的我们感觉不出来，但现在，人工智能加上机器人太炸裂了。」

——他评小米那段视频里的话，2026 年 9 月被重新翻出传播。
:::

## 第三步：解释「为什么是现在」

他给的技术理由只有一个，但很关键——机器人行业的模型路线变了：

| 阶段 | 说明 |
| ---- | ---- |
| 以前 | 机器人按写好的程序做事，哪一步做什么都定死，遇到没写过的情况就停 |
| 现在（VLA 模型） | VLA = 视觉-语言-动作，三个字母分别代表「看」「听懂」「动手」。机器人是看着眼前的情况再决定怎么做 |
| 一句话说清 | 机器人从「照着做」变成「看着做」。这是他认为的拐点 |

::: warning 这一点是行业事实，不是他独有的判断
近两年具身智能赛道确实全面转向 VLA 路线。
:::

## 第四步：所以他给的方向性结论

- 只在屏幕里干活的 AI，机会已经过去了。
- 物理 AI 会是未来十年最值钱的方向。
- 2026 年是物理 AI 开始爆发的第一年。
- 他提到「这个判断和黄仁勋说的一样」。

::: warning 注意这一层利益关系
黄仁勋是做算力生意的，而物理 AI 需要大量算力。所以「物理 AI 是下一个时代」这个判断里，英伟达、机器人整机厂、零部件供应商都有共同的利益共鸣。**这不代表判断是错的，但要知道它为什么被这么多人同时说。**
:::
