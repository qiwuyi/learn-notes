# ③ 模型层：三步选型法

> **学习目标：会做模型选择。**

模型层是「表土层」——AI 原生应用的种子总是从模型为起点，逐渐生根发芽。

选模型不要凭感觉，作者给了一套三步走的方法：

## 第一步：看可用性

先划定**可用范围**，而不是先看排行榜。

> 作者的原话：比如我可以用 GPT，但考虑大部分国内公司只能用国内模型，所以我就限定自己用国内。

也就是说，合规、成本、部署环境、公司政策这些硬约束，第一步就把选项砍掉一大半。

## 第二步：看评测效果

在可用范围内，依据各方官方效果 + Arena 排名，筛选出几个候选。

- Arena 排行榜：[arena.ai/leaderboard/text](https://arena.ai/leaderboard/text)

**为什么更信 Arena 而不是官方分数？**

| 对比项 | 官方发布评分 | Arena 排名 |
| ------ | ------------ | ---------- |
| 题目来源 | 既定的考察题目 | 社区里发布的评分任务 |
| 评测方式 | 针对固定题目打分 | 同一问题随机选两个模型盲选 |
| 用户是否知道出处 | — | 提前不知道结果出自哪个模型 |
| 贴近真实场景程度 | 相对低 | 更接近人类真实认知与工作生活场景 |

## 第三步：看是否适合自己

**真实地把自己的评测集跑一遍**，发现哪个模型好，并列出好的案例。

评测标准至少包括：

1. **回答推理的准确性**
2. **响应速度**

> 作者的真实体验：跑同样一个复杂任务，用 DeepSeek 官方 API 耗时 25 分钟，而切换到 qwen-plus-3.7 只需要 7 分钟。
>
> 同时要注意：即使是同一家（阿里）的 API，也有速度区别——用 token plan 套餐的 token 输出速度远远不及按量付费版本。

![千问 AI 平台控制台截图：Token Plan 与按量付费两套接入地址，标注「模型输出速度远高于 Token plan 版本」](/agent/03-model-selection.png)

*图：同一家平台的两种计费方式——Token Plan 与按量付费，输出速度差异明显。*

::: warning 容易被忽略的一点
**"同一个厂商的不同套餐，速度可以差很多。"** 选型时把「按量付费 vs 套餐」也当成一个变量。
:::

## 如何准备评测集

参考 Langfuse 学院的文章：[如何准备评测数据（Designing Great Datasets）](https://langfuse.com/academy/datasets/designing-great-datasets)

## 三步法小结

```text
① 可用性  ── 合规 / 成本 / 部署 / 政策  → 划定候选池
② 评测效果 ── 官方效果 + Arena 盲测排名  → 缩小到几个
③ 适合自己 ── 自建评测集实跑：准确性 + 速度 → 定稿
```
