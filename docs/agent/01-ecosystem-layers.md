# ① AI 产品生态层级架构

> 本文整理自《产品二姐 ✖️ 言e实验室：Agent 产品基础认知手册》概览章节。

## 用一个类比理解整个 AI 生态

作者把 AI 产品比作草木万物：**地表之上我们看到的是结果，想成为缔造者就得往下深挖。**

这张图的灵感来自她和孩子一起研究土壤层级的感受——植被的分层，正好对应 AI 生态的特点，尤其是每一层对应的「劳作方式」。

## 五层结构

```text
┌─────────────────────────────────────────────┐
│ 草木万物层                                    │
│   各色各样的花、草、小树，也有参天大树           │
│   → 形形色色面向终端用户的 Agent 应用           │
│   劳作方式：日常修剪，帮助它们生长               │
├─────────────────────────────────────────────┤
│ 有机质层                                      │
│   大部分植物的营养来源，需要精耕细作              │
│   → Agent Infra 类产品                        │
│     （提示词、知识库、工具、Skills、记忆）        │
│   劳作方式：浇水、施肥 + 持续监控与改进           │
├─────────────────────────────────────────────┤
│ 表土层                                        │
│   种子播种、扎根、吸收营养的地方                  │
│   → AI 原生应用                               │
│     从模型为起点，逐渐生根发芽                   │
├─────────────────────────────────────────────┤
│ 底土层                                        │
│   坚硬紧密，只有根大而粗壮的植物才能汲取养料       │
│   → 独特的数据 / 算力 / 算法                    │
│     应用发展到一定程度才会拥有                   │
├─────────────────────────────────────────────┤
│ BedRock 层                                    │
│   AWS AI 智算平台的名字也是这个                  │
│   → 上一代云原生为 Agent 备好的基础设施          │
└─────────────────────────────────────────────┘
```

## 逐层解读

| 层级 | 自然界的对应 | AI 生态的对应 | 关键动作 |
| ---- | ------------ | ------------- | -------- |
| 草木万物 | 小花小草小树、参天大树 | 面向终端用户的 Agent 应用 | 持续修剪、迭代 |
| 有机质 | 植物营养的主要来源 | Agent Infra 产品 | 精耕细作 + 持续监控改进 |
| 表土层 | 种子扎根生长处 | AI 原生应用 | 以模型为起点生长 |
| 底土层 | 只有粗壮根系才能取养 | 自有的数据、算力、算法 | 规模化后才具备 |
| BedRock | 最底层基岩 | 云原生基础设施 | 上一代云为 Agent 打好底座 |

::: tip 这张图怎么用
它是一张**定位图**：做产品时先问自己——我的产品站在哪一层？这一层的「劳作方式」是什么？
把 Agent 应用（草木层）和 Agent Infra（有机质层）分开看，能避免把基础设施问题当成应用问题来解决。
:::
