# ① AI 产品生态层级架构

> 本文整理自《产品二姐 ✖️ 言e实验室：Agent 产品基础认知手册》概览章节。

## 用一个类比理解整个 AI 生态

作者把 AI 产品比作草木万物：**地表之上我们看到的是结果，想成为缔造者就得往下深挖。**

这张图的灵感来自她和孩子一起研究土壤层级的感受——植被的分层，正好对应 AI 生态的特点，尤其是每一层对应的「劳作方式」。

![AI 应用生态层级架构：左侧是「劳作方式」，中间是植被分层，右侧对应 AI 生态中的各类产品](/agent/01-ecosystem-layers.png)

*图：AI 应用生态层级架构（产品二姐原图）——左侧「劳作方式」对应右侧每一层的产品形态。*

## 五层结构

| 层级 | 自然界的对应 | AI 生态的对应 | 劳作方式 |
| ---- | ------------ | ------------- | -------- |
| 草木万物层 | 各色各样的花、草、小树，也有参天大树 | 形形色色面向终端用户的 Agent 应用 | 日常修剪、迭代，帮助它们生长 |
| 有机质层 | 大部分植物的营养来源，需要精耕细作 | Agent Infra 类产品（提示词、知识库、工具、Skills、记忆） | 浇水、施肥 + 持续监控与改进 |
| 表土层 | 种子播种、扎根、吸收营养的地方 | AI 原生应用：从模型为起点，逐渐生根发芽 | 以模型为起点生长 |
| 底土层 | 坚硬紧密，只有根大而粗壮的植物才能汲取养料 | 独特的数据 / 算力 / 算法，应用发展到一定程度才会拥有 | 规模化后才具备 |
| BedRock 层 | 最底层基岩（AWS AI 智算平台的名字也是这个） | 上一代云原生为 Agent 备好的基础设施 | 上一代云为 Agent 打好底座 |

::: tip 这张图怎么用
它是一张**定位图**：做产品时先问自己——我的产品站在哪一层？这一层的「劳作方式」是什么？
把 Agent 应用（草木层）和 Agent Infra（有机质层）分开看，能避免把基础设施问题当成应用问题来解决。
:::
