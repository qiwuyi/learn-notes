# 英语与知识 · 播客和频道

选一段感兴趣的内容，边听英语边了解商业、社会和科技。每天不用听完一整期：先听 5 分钟，用一句话说说它讲了什么。

## 从这里开始

根据兴趣选一个就好：

| 频道 | 适合了解什么 | 学习入口 |
| --- | --- | --- |
| Taylor Bell | 商业、工作和个人经历 | [YouTube 频道](https://www.youtube.com/@TaylorBell) |
| CNBC Make It | 商业、工作和生活话题 | [CNBC Make It](https://www.cnbc.com/make-it/) |
| Vox | 社会、文化和科技等话题的解释性视频 | [Vox 视频](https://www.vox.com/videos) |
| Y Combinator | 创业、科技公司和创始人访谈 | [YC 官方资源库](https://www.ycombinator.com/library) |

这些素材面向不同程度的英语使用者。如果听不懂，先看字幕、文字稿或中文解释，挑听懂的一小段即可；Vox 和 YC 也有网站入口。YouTube 等海外平台的可访问性因网络环境而异；CNBC 页面可能受地区或访问限制。

## 早晨怎么学

1. **听或看 5 分钟**：前一天选好一段，早晨直接打开。
2. **回看 3 分钟**：借助字幕或文字稿，弄明白大意，记一个有用的表达。
3. **复述 2 分钟**：用中文或英文回答“它讲了什么？我学到了什么？”

这可以替换[每天十分钟](/growth/)里的当天材料，不需要额外再增加一项任务。完成后照常回到[打卡区](/growth/#记录一下)。
