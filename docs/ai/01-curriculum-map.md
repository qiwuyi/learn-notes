# 课程全景与学习路径

AI 基础专题第一课

## 为什么先做"全景"再深入

AI 领域知识是**层层依赖**的：Embedding 建立在"文本表示"上，Transformer 建立在"注意力"上，RAG 建立在"Embedding + LLM"上。

不先看全景就一头扎进去，很容易"学完了不知道它在哪、跟什么有关"。所以本课先给你地图，再给你路径。

## 24 课全景地图

微软 AI-For-Beginners 按"从符号到神经、从理论到应用"组织：

```text
┌─ ① 入门 ────────────────────────────────────────┐
│  AI 是什么 · 简史 · 符号 AI vs 神经 AI            │
└─────────────────────────────────────────────────┘
        │
        ├────▶ ② 符号 AI（3 课）── 逻辑、知识表示、本体
        │         （现代 AI 的"另一条路"，GPT 之前的主流）
        │
        └────▶ ③ 神经网络（3 课）── 感知机 → 框架
                  │
                  ├──▶ ④ 计算机视觉（7 课）
                  │      CNN → 迁移学习 → GAN → 检测 → 分割
                  │
                  └──▶ ⑤ NLP（8 课）★ 与本站关系最大
                         文本表示 → Embeddings → 语言建模
                         → RNN → Transformer → NER → LLM
                  │
                  ├──▶ ⑥ 其他（3 课）
                  │     遗传算法 · 深度强化学习 · 多智能体
                  │
                  └──▶ ⑦ AI 伦理（1 课）
                        公平 · 责任 · 透明 · 隐私
```

## 各章重点与"值不值得学"

| 章 | 重点 | 对你（RAG/Pi 学习者）的价值 |
| --- | ---- | ---- |
| ① 入门 | AI 定义、历史脉络 | 建立坐标系 |
| ② 符号 AI | 逻辑推理、知识表示 | 了解"另一条路线"，GraphRAG 与它有关 |
| ③ 神经网络 | 感知机、训练原理 | **必修**，一切的基石 |
| ④ 计算机视觉 | CNN、GAN | 可选（不搞 CV 可跳过） |
| ⑤ NLP | Embeddings、Transformer、LLM | **必修**，RAG/Pi 的直接理论底座 |
| ⑥ 其他 | 强化学习、多智能体 | 拓展视野（Agentic 系统与多智能体相关） |
| ⑦ 伦理 | 负责任 AI | 值得了解，实际工程会用上 |

## 三条学习路径

### 路径 A：快速上手应用（4-6 周）
```text
③ 神经网络（了解） → ⑤ 的 Embeddings + Transformer + LLM（重点）
→ 直接进 RAG 专题 → Pi 专题
适合：想快速做出东西的人（你目前在这条路）
```

### 路径 B：扎实打基础（12 周，跟完原课）
```text
① → ② → ③ → ④ → ⑤ → ⑥ → ⑦ 按顺序全部
每课跟读讲义 + 跑 notebook + 做测验
适合：想系统掌握 AI 的人
```

### 路径 C：只补理论（按需查阅）
```text
缺什么补什么：不懂 Embedding → ③ 课；不懂注意力 → ④ 课；
不懂"模型为什么能生成" → ⑤ 课
适合：已经上手、按需回补（推荐配合 RAG/Pi 专题）
```

## 关键衔接点（本站特有视角）

微软课程和你的学习站是**互补**的：

| 微软课 | 本站专题 | 关系 |
| ------ | -------- | ---- |
| 14 Embeddings | RAG B2（Embedding 选型） | 微软讲**原理**（Word2Vec），B2 讲**选型**（怎么挑） |
| 18 Transformers | Pi ②（统一 LLM API） | 微软讲**模型内部**，Pi 讲**怎么调模型** |
| 20 LangModels | RAG ①③（全流程/查询） | 微软讲**模型本身**，RAG 讲**怎么用它** |

**建议**：本站 RAG/Pi 是"应用视角"，微软课是"原理视角"——两边对着看，理解最深。

## 原课程的使用方法

微软课的每课结构（值得学）：
- **README.md**：讲义（图文并茂）
- **notebook**：可运行的代码实验（PyTorch/TensorFlow）
- **Pre/Post 测验**：每课前后的小测验
- **assignment.md**：课后作业
- **sketchnotes**：手绘速记图（很可爱，帮助记忆）

## 小结

- 课程组织：**入门 → 符号 → 神经 → CV → NLP → 其他 → 伦理**
- 对你的价值排序：**NLP（必修）> 神经网络（必修）> 其他章节（按需）**
- 三条路径：快速上手 / 扎实全跟 / 按需补理论
- 和本站是**原理视角 vs 应用视角**的互补
