# 神经网络基础

AI 基础专题第二课 · 基于微软课程第 3 章

::: tip 本课目标
理解现代 AI 的"积木"——神经网络：感知机怎么分类、权重怎么训练、深层网络为什么更强。
学完你就知道 LLM 的"训练"到底在做什么。
:::

## 起点：感知机（1957）

1957 年 Rosenblatt 造出 **Mark-1 感知机**——用硬件（20×20 光电管 = 400 输入）识别三角形/正方形/圆。

数学上，感知机是**二分类模型**：

```text
输入向量 x（N 个特征）
权重向量 w（每个特征一个权重）
输出 y = f(wᵀx)，f 是阶跃函数：

f(z) = +1  (z ≥ 0)
       -1  (z < 0)
```

直观理解：**加权求和 + 阈值判断**。

```text
例子：判断"今天要不要出门"
特征：x1=下雨(1/0)，x2=有工作(1/0)，x3=温度
权重：w1=-2（下雨很减分），w2=+3（有工作必出门），w3=+0.1
输出 = f(-2·x1 + 3·x2 + 0.1·x3) → 分数高就"出门"
```

权重就是"每个因素多重要"——而训练就是**自动找到最好的权重**。

## 训练：让误差最小化

感知机训练（1957 年的算法）很简单：

```text
1. 初始化权重（随机）
2. 拿一个样本，算输出
3. 分错了 → 按错误方向微调权重
   w = w + η·x·t    （η 学习率，t 真实标签）
4. 重复直到大部分分对
```

误差函数（perceptron criterion）：

```text
E(w) = -Σ wᵀxᵢtᵢ   （只对分错的样本求和）
```

关键洞察：**"训练"= 不断调整权重让错误减少**。这个朴素想法就是所有深度学习的基础。

## 从感知机到多层网络

单感知机只能分**线性可分**的问题（画一条直线分开两类）。1969 年 Minsky 指出它连 XOR 都分不了 → AI 进入冬天。

解法：**多层网络**（把多个感知机叠起来）：

```text
输入层 ──▶ 隐藏层 ──▶ 隐藏层 ──▶ 输出层
  x          h1          h2         y

每层的每个"神经元"：
  z = Σ(wᵢ·xᵢ) + b     ← 加权求和 + 偏置
  a = 激活(z)           ← 非线性变换（关键！）
```

**为什么需要激活函数？** 没有非线性，多层 = 一层（线性叠加还是线性）。激活函数（sigmoid/ReLU）引入弯曲，网络才能拟合复杂边界。

## 反向传播：多层的训练算法

感知机算法只适用于单层。多层网络用 **反向传播（Backpropagation，1986）**：

```text
① 前向传播：输入 → 逐层计算 → 得到输出
② 算误差：输出 vs 真实标签的差距（损失函数）
③ 反向传播：从输出层开始，逐层往回算"每个权重对误差的贡献"（梯度）
④ 更新：w = w - η·梯度   （梯度下降，往误差减小的方向走）
```

直觉：像调试电路——先看最终输出错多少，再往回找"是哪一层、哪个权重导致的"，逐个修正。

## 训练的三个核心概念

| 概念 | 含义 | 直觉 |
| ---- | ---- | ---- |
| **损失函数** | 衡量"错得多离谱" | 考试的分数 |
| **梯度下降** | 沿误差减小方向更新权重 | 下山：每步走最陡的坡 |
| **学习率 η** | 每步走多大 | 太大翻车，太小龟速 |

## 用框架：从手写到 TensorFlow/PyTorch

微软课程第 5 课演示了：先**手写**一个简单框架（理解原理），再用 **PyTorch/TensorFlow**（工程实践）。

手写框架能加深理解（就几百行），但真实项目直接用框架：

```python
# PyTorch 版感知机（概念示意）
import torch.nn as nn
model = nn.Sequential(
  nn.Linear(400, 100),   # 400 输入 → 100 隐藏
  nn.ReLU(),             # 激活
  nn.Linear(100, 1),     # → 1 输出
)
```

## 和 LLM / RAG 的关系

```text
本课：感知机 → 多层网络 → 训练
  ↓ 堆积更多层、更多数据、更多算力
深度学习（本课的延伸）
  ↓ 特殊结构
Transformer（第 ④ 课：注意力替代循环）
  ↓ 大规模预训练
LLM（GPT/Claude）──▶ 被 RAG 专题调用
```

你现在学 RAG/Pi 时见的每个模型，底层都是**这节课讲的加权求和 + 激活 + 梯度下降**。

## 自测

::: details 测验 · 点击展开

**1. 感知机的本质是？**
- ✅ **加权求和 + 阈值判断 的二分类模型**
- ❌ 一种编程语言
- ❌ 一种数据库
- ❌ 一个 API

**2. "训练"在神经网络里的本质是？**
- ✅ **不断调整权重，让损失函数（误差）最小**
- ❌ 写更多代码
- ❌ 增加网络层数
- ❌ 更换激活函数

**3. 激活函数为什么必要？**
- ✅ **引入非线性，否则多层网络等价于单层**
- ❌ 让训练更快
- ❌ 它是可选的装饰
- ❌ 减少参数量

**4. 反向传播做什么？**
- ✅ **从输出层往回算每个权重对误差的贡献（梯度），用于更新**
- ❌ 让数据反向输入
- ❌ 翻转模型结构
- ❌ 删除错误的神经元

**5. 学习率太小/太大的后果？**
- ✅ **太小训练龟速；太大可能震荡甚至发散（翻车）**
- ❌ 没有区别
- ❌ 太小发散，太大龟速
- ❌ 只影响内存

:::

## 小结

- 感知机 = **加权求和 + 阈值**，1957 年就有的二分类模型
- 训练 = **调权重让误差最小**（梯度下降 + 反向传播）
- 激活函数给多层网络**非线性**能力
- 所有现代模型（LLM 等）底层都是这节课的原理
